# TalvBot

A robot-run gacha capsule machine on BNB Chain — live at https://talv.site

- 999 capsules, one pool shared by free and paid spins
- Paid spin from 0.0008 BNB (price steps to 0.0015 as supply fills), tier revealed in the mint transaction: Common 62% / Rare 30% / Legendary 8%
- Every 100th paid spin wins a 0.025 BNB jackpot, paid instantly in the same transaction — no claim step anywhere
- One free spin per wallet for Binance Agent ID holders (Common/Rare only)
- Contract: TalvBot.sol (ERC-721, symbol TBOT) — address announced at launch
- Agents: see skill.md, mint.json, llms.txt, agents.txt
- Owner deploy: deploy.html (not linked from the public site)
